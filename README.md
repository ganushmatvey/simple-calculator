# Simple Calculator

> Простой консольный калькулятор на Python, созданный для практики работы с функциями, обработки ошибок и оформления строк документации (Docstrings).

### Особенности
* **Математика:** Сложение, вычитание, умножение и деление.
* **Безопасность:** Защита от деления на ноль и ввода не числового типа данных.
* **Документация:** Каждая функция оформлена по стандарту PEP 257.

### Запуск
```bash
python first_program.py
```
