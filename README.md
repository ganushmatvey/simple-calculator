# 🧮 Консольный калькулятор на Python

Простой калькулятор, написанный на **Python 3.11+** в учебных целях. 

### Что реализовано:
* **Математика:** сложение, вычитание, умножение, деление и возведение в степень.
* **Безопасность:** обработка ошибок ввода и защита от деления на ноль.
* **Удобство:** возможность выхода из программы в любой момент.
